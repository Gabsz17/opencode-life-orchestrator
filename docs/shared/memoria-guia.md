# Memoria compartilhada — guia (Estudos + Grana)

> `.opencode/memory/MEMORIA.md` unica; inboxes por agente em `.opencode/memory/inbox/`.

## Ciclo
1. **INICIO**: leia `MEMORIA.md` + `progresso.md` do dominio ativo + PLANO do dominio. Distribua relevante nas Tasks.
2. **FIM**: ate 3 licoes no inbox proprio (`.opencode/memory/inbox/<agente>.md`).
3. **Promocao**: dedupe util para `MEMORIA.md` (teto 60 itens; recentes FIFO max 30).
4. Licao vista 3x = `Regra permanente`.

## Limites
- Nunca grave: segredo, token, CPF, saldo, chave privada, dados pessoais de aluno.
- Commite memoria junto de marcos: `docs: atualiza memoria`.
- Inboxes consumidos: esvaziar via `edit` (nunca `rm -rf`).

## Formato inbox
```markdown
## Aprendizado
- <licao curta>
- Evidencia: <arquivo:linha ou fonte+data>
- Data: YYYY-MM-DD
```
