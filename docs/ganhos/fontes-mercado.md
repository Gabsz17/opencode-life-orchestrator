# Fontes mercado — BCB, CVM, B3, Tesouro, SEBRAE, TSE, IBGE

> Conteudo educacional. Ver [disclaimer](disclaimer.md).


> Fontes oficiais para trilhas de Grana. Acesso base: 2026-10-25.

## Renda fixa / macro (BCB)
- SGS API (series oficiais, ex. Selic 432): `https://api.bcb.gov.br/dados/serie/bcdata.sgs.432/dados/ultimos/1?formato=json`
- Focus/Relatorio Focus (expectativas): `https://www.bcb.gov.br/estabilidadefinanceira/relatoriafocus`
- Copom (atas e decisoes): `https://www.bcb.gov.br/publicacoes/atacopom`

## Tesouro Direto
- Precos (API): `https://www TesouroDireto.gov.br/api/treasurybondes/quotedPrice` (via portal oficial `https://www.tesourodireto.com.br/`)
- RMD — Relatorio Mensal de Dados: `https://www.gov.br/tesouronacional/pt-br/nao-classificado/relatorio-mensal-de-dados`

## CVM / B3 (renda variavel)
- CVM dados abertos (22 conjuntos): `https://dados.cvm.gov.br/`
- B3 cotacoes (delay 15 min): `https://www.b3.com.br/pt_br/produtos-e-servicos/negociacao/renda-variavel/`
- Manuais/valores oficiais B3: `https://www.b3.com.br/pt_br/produtos-e-servicos/negociacao/`

## Cripto (regulacao Brasil)
- BCB Res. 5.17/5.19/5.20/5.21 (regras prove-to-ve-to/custodia): `https://www.bcb.gov.br/`
- DeCripto / Receita (IN 2.291/2025 — declaracao cripto): `https://www.gov.br/receitafederal/`

## Negocios / MEI / SEBRAE
- MEI (limites gov.br): `https://www.gov.br/empresas-e-negocios/gerar/mei`
- SEBRAE (custos, precificacao, negocios locais): `https://www.sebrae.com.br/`

## Eleicoes 2026 (SENSIVEL)
- TSE dados abertos / prestacao de contas: `https://dadosabertos.tse.jus.br/`
- Lei 9.504/1997 + Res. TSE 23.610/2019: sempre citar `base_legal` quando `eleitoral=true`.

## IBGE
- SIDRA/PNAD/PMC: `https://sidra.ibge.gov.br/`

## Como citar
`[BCB SGS 432 em 2026-10-25](https://api.bcb.gov.br/...) — acesso 2026-10-25`. Sem fonte = `nao confirmado`.
