# Fontes ENEM — Matriz, Edital, Provas INEP, Marp, Direitos

> Conteudo educacional. Ver [disclaimer](disclaimer.md).


> Fontes oficiais para trilhas ENEM. Acesso base: 2026-10-25.

## Matriz de Referencia + Edital
- INEP Matriz ENEM 2024+ (competencias/habilidades por area): `https://www.gov.br/inep/pt-br/areas-de-atuacao/avaliacao-e-exames-educacionais/enem/matriz-de-referencia`
- Edital ENEM 2026 (cronograma, regras, recursos): `https://www.gov.br/inep/pt-br/acesso-a-informacao/editais/enem-2026`

## Provas Oficiais (repositorio INEP)
- Provas + gabaritos 2009-2025: `https://www.gov.br/inep/pt-br/areas-de-atuacao/avaliacao-e-exames-educacionais/enem/provas-e-gabaritos`
- Download ZIP por ano (prova + gabarito + caderno): `https://download.inep.gov.br/enem/`

## Marp (slides)
- Documentacao Marp: `https://marpit.marp.app/` + `https://github.com/marp-team/marp-cli`
- Tema recomendado: `marp: true` + `theme: uncover` + `paginate: true`

## Direitos Autorais / Uso
- INEP: uso educacional nao comercial permitido (citando fonte). Questoes nao podem ser alteradas.
- Banco pago (Descomplica, Stoodi, etc.) = PROIBIDO copiar/redistribuir.
- Questoes `autoral — padrao ENEM` = criadas pelo modo, marcadas como tal.
