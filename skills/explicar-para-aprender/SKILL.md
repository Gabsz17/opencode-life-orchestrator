# Explicar para aprender

Use ao escrever conceito, exemplo, slide ou feedback. Explicar de verdade = teste de compreensão; parafrasear = ilusão.

## Protocolo

1. **Um "por quê?" por fato** — para cada fato novo, pergunte "por que isso faz sentido?" e responda com o que já sabe.
2. **Autoexplique o exemplo** — a cada passo resolvido, diga o que significa + a que princípio se liga; declare onde travou.
3. **Ensine simples** — reescreva de memória em linguagem simples (como para um iniciante), com 1–2 exemplos próprios.
4. **Caçe o jargão** — todo termo técnico não explicado volta à fonte; analogia só vale se checada com a fonte oficial.
5. **Feche o gap** — volte à fonte SÓ nos pontos travados, corrija a explicação e repita espaçado.

## Proibido

- Parafrasear a fonte e chamar de "entendi" (sem "por quê?" não conta).
- Feynman sem recall prévio (olhando a lição enquanto "ensina").
- Analogia inventada sem checagem; conteúdo sem fonte sai marcado `não confirmado`.
